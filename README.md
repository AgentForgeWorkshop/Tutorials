# AgentForge Workshop — Tutorials

Hands-on notebooks introducing AI agents for scientific work. Each tutorial is a
self-contained Google Colab notebook: no local setup, no paid API required.

| # | Tutorial | What you build |
|---|---|---|
| 1 | [Intro_mini_agent](Tutorial1_mini_agent/) |Introduction to agent loop via an in-house code "mini_agent" by Shichuan Sun |
| 1 | [Intro_agent frameworks](Tutorial1_frameworks/) | The agent loop, written by hand and then in LangChain: an assistant that searches arXiv, summarises papers and returns a literature table |

Start with Tutorial 1 — it establishes the mental model (an agent is a short loop around an
LLM and some Python functions) that the rest build on.
