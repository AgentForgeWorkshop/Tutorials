# Tutorial 2: Agentic Memory

Tutorial lead: Yukun Xue (Xidian University).

The hands-on notebook adds memory to `mini_agent`, the agent from Tutorial 1, following the four
parts of the lecture: why agents need memory; what to store, and how to write and read it; the
routes into the context; cost and evaluation. Offline mode needs no API key: model replies come
from a recorded live run, while the tools run for real. With your own key, or the workshop key
through the optional OpenRouter cell, the same cells run live.
